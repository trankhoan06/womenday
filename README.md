# 🌸 Trang Web Chúc Mừng Ngày Phụ Nữ

Trang web chúc mừng ngày Phụ Nữ dành riêng cho 4 người phụ nữ tuyệt vời:
- **Nguyễn Thị Ty**
- **Trần Liên**
- **Trần Ngân Vàng**
- **Hồ Thị Diệu Linh**

---

## 🌟 Điểm nổi bật & Hiệu ứng

1. **Giao diện hiện đại & lãng mạn:** Phong cách Glassmorphism, tone màu Rose Gold & Soft Pink lung linh, Typography chuẩn Google Fonts.
2. **Hiệu ứng chuyển động (Animation & Particles):**
   - Mưa cánh hoa & trái tim rơi nhẹ nhàng trên Canvas với vật lý đung đưa mượt mà.
   - Hiệu ứng pháo hoa Confetti lung linh khi mở thiệp chúc mừng.
   - Thả tim bay lơ lửng khi chạm hoặc click vào bất kỳ đâu trên màn hình.
3. **Tương tác cá nhân hóa:**
   - Mỗi người đều có một **Thẻ Vinh Danh** với lời chúc & danh hiệu riêng biệt.
   - Bấm **"Xem Lời Chúc Riêng"** để mở phong bao thư chứa các lời chúc đặc biệt.
   - Nút **"Rút Quẻ May Mắn"** ngẫu nhiên lời chúc tốt lành.
   - Nút **"Gửi Yêu Thương"** kèm bộ đếm hoa & trái tim lưu trực tiếp.
4. **Nhạc nền du dương:** Nút đĩa nhạc ở góc phải cho phép bật/tắt điệu nhạc lãng mạn.
5. **Chuẩn Responsive:** Hiển thị mượt mà trên iPhone, Android, iPad, Laptop và Màn hình lớn.

## 🚀 Hướng Dẫn Đẩy Lên Vercel (Rất Đơn Giản)

### Cách 1: Đẩy qua GitHub (Khuyên dùng)
1. Đẩy toàn bộ thư mục này lên một repository GitHub mới:
   ```bash
   git add .
   git commit -m "Happy Women's Day Website"
   git push origin main
   ```
2. Đăng nhập [vercel.com](https://vercel.com).
3. Chọn **Add New...** -> **Project** -> Chọn repo vừa tạo.
4. Nhấn **Deploy** (không cần cấu hình gì thêm vì đây là HTML/CSS/JS thuần). Vercel sẽ tự động tạo link web trực tiếp trong vài giây!

### Cách 2: Dùng Vercel CLI
Nếu bạn đã cài Vercel CLI trên máy, mở terminal tại thư mục này và gõ:
```bash
vercel
```
Nhấn Enter để xác nhận các thiết lập mặc định.
